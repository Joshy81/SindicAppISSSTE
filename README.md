# 📱 SindicAppISSSTE

Aplicación multiplataforma para consulta de normatividades y documentos del Sindicato ISSSTE.

---

### 📥 Enlaces de Instalación y Descarga

* 🍎 **iPhone / iPad (iOS):** Abre [SindicAppISSSTE Web](https://Joshy81.github.io/SindicAppISSSTE/) en Safari, presiona *Compartir* y selecciona **"Agregar a inicio"**.
* 🤖 **Android:** Descargar [SindicAppISSSTE.apk](https://github.com/Joshy81/SindicAppISSSTE/releases/download/v1.0.0/SindicAppISSSTE.apk) *(Instalador directo)*.
* 💻 **Windows PC (Portable):** Descargar [SindicAppISSSTE_Portable.zip](https://github.com/Joshy81/SindicAppISSSTE/releases/download/v1.0.0/SindicAppISSSTE_Portable.zip) *(Ejecutable sin instalación)*.
* 💻 **Windows PC (Win-Unpacked):** Descargar [SindicAppISSSTE_WinUnpacked.zip](https://github.com/Joshy81/SindicAppISSSTE/releases/download/v1.0.0/SindicAppISSSTE_WinUnpacked.zip) *(Sistema completo comprimido)*.
